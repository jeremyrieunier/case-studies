# Data Analytics Case Studies

This repository contains a collection of anonymized case studies completed for job interviews. Each case study demonstrates different technical skills and approaches to solving real-world business problems.

## Case Studies Overview

### [Data Modeling Case Study](./data-modeling-case-study/)
An analysis of a dimensional data model for a payment processing system, created for an Analytics Engineer position. Features:
- Star schema analysis and improvement
- SQL query development for business intelligence
- Revenue and year-over-year growth analytics

### [Product Analysis Case Study](./product-data-analyst-case-study/)
A comprehensive analysis for a sports booking platform including, created for a Product Data Analyst position. Features:
- SQL query development for user and revenue analysis
- A/B testing methodology for new feature implementation
- Time series forecasting with Prophet

### [Growth Analytics Case Study](./growth-data-analyst-case-study/)
A market sizing and attribution modeling project, created for a Senior Growth Data Analyst position. Features:
- Outbound opportunity analysis and TAM sizing
- Growth channel prioritization
- E-commerce data analysis with SQL attribution modeling

## Skills Demonstrated

This portfolio showcases technical expertise in:

- **SQL**: Complex queries, CTEs, window functions, joins, attribution modeling
- **Data Modeling**: Star schemas, dimensional modeling, key management
- **Python**: Time series forecasting with Prophet, data manipulation, analysis
- **Business Intelligence**: KPI development, attribution modeling, metrics design
- **Growth Strategy**: TAM analysis, channel prioritization, acquisition mix optimization
- **A/B Testing**: Experimental design, metric selection, statistical analysis
- **Analytics Engineering**: Data transformation, modeling, optimization

## Interactive Visualization

The case studies were presented using modern data visualization frameworks:

### Evidence.dev
The Growth Analytics case study was presented using [Evidence.dev](https://evidence.dev), an open-source framework for building data applications with SQL. This provided an interactive experience with:
- Live SQL-driven visualizations
- Dynamic filtering capabilities
- Publication-quality charts and tables
- Narrative context alongside data insights

### Streamlit
The Product Data Analysis case study was presented using [Streamlit](https://streamlit.io), a Python-based framework for creating interactive data applications. This allowed for:
- Python-based data processing and visualization
- Interactive Prophet forecasting components
- Dynamic SQL query execution and result display using DuckDB
- Integration of visualizations with analytical narrative

## Repository Structure

Each case study is organized in its own directory with:
- A README file explaining the problem, approach, and skills demonstrated

- My detailed solution with analysis and code
