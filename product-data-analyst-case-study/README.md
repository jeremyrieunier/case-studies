# Product Data Analyst Case Study

## Overview
This case study demonstrates a comprehensive data analysis for a padel court booking platform. The analysis spans 3 critical areas of product analytics: SQL data exploration, A/B testing methodology, and forecasting user growth using Python.

## Project Structure

This repository is organized into 4 main files:

1. **01_assignment.md** - The original case study requirements, detailing:
   - Company background and product description
   - Database structure and sample data
   - Specific analytical tasks

2. **02_sql.md** - SQL queries and analysis covering:
   - User demographics and segmentation
   - Cross-product usage patterns
   - Revenue metrics by country
   - User activity ranking
   - Conversion funnel analysis

3. **03_ab-testing.md** - Comprehensive A/B testing strategy for a new feature:
   - Experiment duration planning
   - Rollout methodology
   - Metric selection (primary and guardrail metrics)
   - Expected outcomes and success criteria

4. **04_forecasting.md** - Monthly Active User (MAU) growth forecasting:
   - Time series analysis using Prophet
   - Contract cost implications
   - Multiple scenario planning

## Skills Demonstrated

This case study showcases expertise in:

- **SQL Data Analysis**: Complex queries using CTEs, window functions, and joins
- **A/B Testing Design**: Experimental methodology, statistical considerations, and metric selection
- **Time Series Forecasting**: Prophet modeling with scenario planning
- **Business Intelligence**: Translating data insights into actionable recommendations
- **Product Analytics**: Understanding user behavior and conversion optimization

## Tools Used

- SQL
- Python + Prophet (time series forecasting)
- Streamlit (to present the case study with interactive visualization)

*This case study has been anonymized to protect company-specific information while preserving the analytical approach and methodologies used.*
