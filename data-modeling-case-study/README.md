# Data Modeling Case Study
## Overview

This case study demonstrates dimensional data modeling for an international payment processing platform. The assignment focused on analyzing an existing data model, describing its structure, and writing SQL queries to answer business questions.

## Repository Structure
- `assignment.md`: The original task requirements
- `modeling.md`: My detailed analysis and solution

## Skills Demonstrated
- **Data Model Analysis**: Identification and description of dimensional modeling patterns
- **Star Schema Understanding**: Recognition of fact and dimension table structures
- **SQL Query Development**: Writing complex SQL for business analytics
- **Data Optimization**: Proposing improvements to the existing data model design
- **YoY Analysis**: Creating comparative metrics for year-over-year business performance

## Solution Highlights
The solution includes:
1. A thorough analysis of the provided star schema model
2. Identification of the fact table (Transaction) and dimension tables (Date, Country, Account, Payment Method, Portal)
3. SQL queries that answer critical business questions about revenue and growth
4. Proposed improvements to the data model through better key management
5. Usage of CTEs for complex YoY analysis with multiple dimensions

## Tools & Techniques Used
- SQL (for query development)
- Dimensional Modeling principles
- Star Schema design
- Common Table Expressions (CTEs)
- Full Outer Joins (for comprehensive YoY analysis)
